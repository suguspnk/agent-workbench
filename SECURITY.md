# Security Policy

## Reporting a vulnerability

Do not publish vulnerabilities, secrets, credentials, or proof-of-concept details in a public issue. Report a potential vulnerability affecting Agent Workbench through a [private GitHub security advisory](https://github.com/suguspnk/agent-workbench/security/advisories/new).

Include the affected version or commit, a minimal reproduction, impact, and any suggested mitigation. Remove secrets and unrelated private data before submitting the report.

## Scope

This policy covers the files packaged in this repository. It does not make an agent harness, provider, model, tool, or third-party plugin part of this repository's security boundary.
